# ADR-0006: Datasets kept for reference only

Status: accepted (2026-10-25).

Edge-IIoTset (not in the finalised dataset plan) and the ids-adapt processed parquets (built for an earlier
project, probably from uncorrected CIC releases) are profiled for the record but not preprocessed, and no
reported number uses them. NSL-KDD is preprocessed as a historical baseline only.
